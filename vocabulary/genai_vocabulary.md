# Generative AI Vocabulary

**Course:** EPAM Tech Orda — GenAI Master Program  
**Author:** Anton Danchev  
**Date:** November 2026

## 1. Artificial Intelligence (AI)

AI is a technology that helps computers solve problems and perform tasks that usually require human intelligence.

**Example:** AI can recognize images, analyze information, and help people make decisions.

## 2. Generative AI (GenAI)

Generative AI is a type of AI that can create new content, such as text, images, music, or programming code.

**Example:** I use GenAI to generate educational materials and help with software development.

## 3. Large Language Model (LLM)

An LLM is an AI model trained on a large amount of text. It can understand questions and generate answers in natural language.

**Example:** ChatGPT uses language models to answer questions, explain code, and help users with different tasks.

## 4. Prompt

A prompt is a question or instruction that we give to an AI model to get a result.

**Example:** When I ask ChatGPT to write a Python function, my request is a prompt.

## 5. Hallucination

A hallucination happens when AI generates information that looks correct but is actually wrong.

**Example:** Sometimes AI suggests Python functions that do not exist in the real library.

## 6. Token

A token is a small part of text that an AI model uses
to process information. It can be a word, part of a word,
or even a single character.

**Example:** When I send a message to ChatGPT,
the model splits my text into tokens before processing it.

## 7. Neural Network

A neural network is a computer system inspired by
the human brain. It uses connected artificial neurons
to learn patterns from data.

**Example:** Neural networks can recognize objects
in images and understand spoken language.

## 8. Deep Learning

Deep learning is a type of machine learning that uses
neural networks with many layers to learn complex patterns.

**Example:** Deep learning is used in image recognition,
speech processing, and modern AI language models.

## 9. Retrieval-Augmented Generation (RAG)

RAG is a technique that allows AI to search for
information in external sources before generating
an answer.

**Example:** An AI chatbot can use RAG to find
information in a company's knowledge base and
answer customer questions more accurately.

## 10. Fine-tuning

Fine-tuning is the process of training an existing
AI model on additional data to improve its performance
for specific tasks.

**Example:** A company can fine-tune a language model
using specialized documents to improve its answers
in a particular field.
